📖 Tool Controls

🟦 Drawing Paths
  • Left Click & Drag: Draw a new path line.
  • Left Click: Drop points to draw a chained path.
  • ESC Key: Break the active drawing chain.
🟩 Dropping Rooms
  • Left Click: Drop a room near a path. It will auto-snap a connector.
🖱️ Editing (Right-Click)
  • Right Click: Select a node or path to open the Inspector.
  • Right Click & Hold: Drag to move an existing node.
  • Delete Key: Remove selected object.
↩️ History
  • Ctrl + Z: Undo
  • Ctrl + Y: Redo
